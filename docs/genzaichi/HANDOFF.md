## 3. 決めたこと（デザイン・文体の方針）

### 文体
- **見出し**: 短い言い切り。体言止めのキャッチコピー調・対句は使わない
- **本文**: 一人称の「です・ます」。企画者本人が説明している口調
- 排除した語彙: 「本質」「価値」「生命線」「〜こそが」「可視化」など、いわゆるAI／コンサル調の言い回し
- タグライン `「まだ、途中です。」` は残した（表紙裏の3枚目と最終ページで使用）

### 配色（3色のみ）
| 役割 | HEX | 使いどころ |
|---|---|---|
| ink（主色・暗） | `12161C` | 暗いページの背景、明るいページの本文色 |
| ink card | `1E2630` | 暗いページのカード地 |
| paper（明） | `F4F5F6` | 明るいページの背景 |
| paper card | `E7E9EB` | 明るいページのカード地 |
| frost | `C9D2D9` | 暗い地の本文 |
| slate | `7E8B96` | 補助テキスト |
| **ember（アクセント）** | `E2542C` | 見出しラベル、数字、強調 |
| ember（明地用） | `B8431F` | 明るい地の上で使うとき（コントラスト確保のため濃く） |

明暗をサンドイッチに配置している（表紙=暗 / 背景=明 / コンセプト=暗 / …）。

### フォント
- 見出し: `Yu Mincho`（游明朝）
- 本文: `Yu Gothic`（游ゴシック）
- 英数字・数値: `Arial`

### 繰り返しモチーフ
- 各ページ右上に **大きな薄いページ番号**（01〜16）
- 各ページ左上に **ember色の英字ラベル**（`WHY NOW ／ 背景` など）
- 装飾用の色帯・アンダーラインは一切使っていない

## 5. 修正した不具合（同じ罠を踏まないための記録）

| 不具合 | 原因 | 対処 |
|---|---|---|
| 箇条書きの記号が1行目にしか出ない | `bullet` を段落単位ではなくテキストボックス全体に指定していた | 各項目の `options` に `bullet` を付ける（`bullets()` ヘルパーに集約） |
| 本文が箱の中で上下中央に寄り、行数の違うブロック同士で高さが揃わない | pptxgenjs のテキストボックスは既定で縦中央寄せ | すべての本文に `valign: "top"` を明示 |
| シーズン1ページで注記がカードに重なる | カード高 1.6 × 2段 で下端が注記の位置を超えていた | カード高を 1.5 に、段間を 0.28 に調整 |
| 長い見出しが右上のページ番号に食い込む | 見出しが箱幅を超えても pptx は切り詰めず溢れる | 見出しの文字数で自動的にサイズを落とす処理を追加（22字以上=27pt / 19字以上=30pt / それ以外=33pt） |
| 予算ページの「約 84 万円」の「約」が数字と同じ大きさ | 1つのテキストランに「約 84」をまとめていた | 「約」「84」「万円」を3つのランに分割 |
| 被写体ページの1枚目だけ本文が3行になり下に詰まる | 文が長かった | 文を短縮＋カード高を 1.34 → 1.40 に |

**pptxgenjs で今後ハマりそうな点**
- 色に `#` を付けるとファイルが壊れる（`"E2542C"` と書く）
- オプションのオブジェクトを使い回すと壊れる（毎回新しく作る）
- 影の `offset` は負の値にできない
- `rectRadius` は `ROUNDED_RECTANGLE` にしか効かない

## 6. build-deck.js の構造（どこを触ればどこが変わるか）

```
先頭 30行      … 配色・フォント・キャンバスサイズの定数。ここを変えると全ページに効く
base()         … 明るいページ / 暗いページの土台
head()         … 右上のページ番号・左上の英字ラベル・見出し・小見出し・フッターを一括で置く
card()         … 角丸カード
bullets()      … 箇条書き（段落ごとに記号を付ける版）
numDisc()      … ember色の丸に数字を入れたアイコン
その後         … 「01 表紙」〜「18 クロージング」までページごとのブロックが順番に並ぶ
```

各ページのブロックは独立しているので、1枚だけ直したいときはそのブロックだけ触ればいい。
文言はすべて配列リテラルに直書きしてあるので、検索すればすぐ見つかる。

## 7. まだ決まっていないこと・要判断

- **被写体が1人も決まっていない**。シーズン1の6本（釧路の水産加工二代目 / 根室の酪農 / 帯広の元飲食店主 / 羅臼の漁師 / 札幌のものづくり / 道東Uターン）は全部仮案。スライドにも「仮」と明記済み
- **予算・KPI はすべて想定値**。1本14万円 / シーズン6本で84万円 / 完了率30% / 問い合わせ12件 / 協賛1〜2社 — パイロット1本を撮った時点で実績に差し替える前提
- **制作者名・連絡先を入れていない**。表紙と最終ページに入れる場合は要追記
- **ロゴがない**。いまは Arial の字間を開けた文字組みで代用している
- **写真・映像のスチルが1枚も入っていない**。パイロットを撮ったら、表紙・被写体ページ・ラインナップページに実写を入れると一気に説得力が上がる（いまは意図的に文字だけで構成している）

ETHICS & RISK ／ 倫理
出てくれた人を守れないなら、撮りません
綺麗事を撮らないことと、人を傷つけることは違います。その線引きだけは、撮る前に仕組みとして決めておきます。

同意と、取り下げ
見世物にはしません
書面での同意と、公開前の試写は必ずやります。公開した後も、期限なしで取り下げの申し出を受けます。
貧しさや失敗や病気を、画の強さのために使いません。演出で不幸を足すことは絶対にしません。

本人以外への配慮
素材の管理
本人以外が特定される話は、本人の許可があっても慎重に扱います。家族、従業員、取引先です。
暗号化した外付けに二重でバックアップします。未公開の素材は、関係者にも渡しません。

途中でやめるとき

切り抜かれて広がる前提で作ります。単体で誤解される画は本編に置きません。窓口と手順も先に決めます。
