# GENZAICHI（現在地）企画書

映像作家・カメラマンとして立ち上げるドキュメントメディア「GENZAICHI」の企画書。
北海道（道東中心）で、経営者から名前の出ない人まで、人生の「現在地」をショートフィルムで記録する。

- `GENZAICHI_企画書.pptx` … 本体（16:9 / 全18枚 / スピーカーノート付き）
- `build-deck.js` … 上記 pptx の生成スクリプト（pptxgenjs）

## 構成（18枚）

| # | 内容 |
|---|---|
| 1 | 表紙 |
| 2 | 背景（なぜ今か） |
| 3 | コンセプト（現在地の定義） |
| 4 | 編集方針（撮らないもの／撮るもの） |
| 5 | 被写体の選び方 |
| 6 | 映像フォーマット（尺・5章構成） |
| 7 | インタビュー設計（設問リスト） |
| 8 | 撮影方針 |
| 9 | 制作フロー（7ステップ・本人試写のルール） |
| 10 | 配信・展開 |
| 11 | シーズン1 企画案（仮） |
| 12 | 収益モデル |
| 13 | 制作体制 |
| 14 | スケジュールと初年度目標 |
| 15 | 予算感 |
| 16 | 倫理とリスク |
| 17 | 3年ロードマップ |
| 18 | クロージング |

## 数字の扱い

予算・KPI・シーズン1のラインナップは、いずれも**たたき台の想定値**。
パイロット1本を撮った時点で実績に差し替える前提で置いている。
被写体・地域名も仮案であり、実際の人選は事前面談を経て決める。

## 再生成

```bash
npm install pptxgenjs        # このリポジトリ本体の依存とは別（未導入なら）
node docs/genzaichi/build-deck.js docs/genzaichi/GENZAICHI_企画書.pptx
```

文言・配色・構成はすべて `build-deck.js` 内にまとまっている。
配色は ink（`12161C`）／frost（`C9D2D9`）／ember（`E2542C`）の3色。
